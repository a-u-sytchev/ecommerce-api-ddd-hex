# API электронной коммерции

Это API для электронной коммерции.

## Используемые технологии

* **Docker**: контейнеризация
* **Spring Boot (Kotlin)**: backend-фреймворк
* **Redis**: кэш
* **PostgreSQL**: база данных
* **RabbitMQ**: очередь сообщений
* **Swagger UI**: документация API доступна по адресу http://127.0.0.1:8080/swagger-ui
* **Flyway Migrations**: миграции базы данных
* **Spring Security**: безопасность
* **Spring Actuator**: мониторинг
* **Spring Data JPA**: работа с данными
* **MockK и JUnit**: модульные и интеграционные тесты

## Настройка

1. **Запуск базы данных и сервера:**

    * Перейдите в папку `docker`.
    * Выполните команду `docker compose up`. Это запустит базу данных и сервер очередей.

2. **Запуск приложения**

3. **Доступ к endpoint'ам:**

    * Spring Security изначально заблокирует доступ ко всем endpoint'ам и запросит аутентификацию.
    * Пользователь по умолчанию — `user`, пароль генерируется при запуске приложения. Его можно посмотреть в консоли.

4. **Swagger UI:**

    * Откройте Swagger UI по адресу http://localhost:8080/swagger-ui, чтобы посмотреть подробную документацию по каждому endpoint'у.

## Основные функции

### Создание аккаунта с ролью доступа

* **Роли:**

    * Системный администратор
    * Владелец магазина
    * Покупатель

### Покупатели могут:

* Просматривать товары.
* Добавлять товары в избранное и просматривать список избранного.
* Добавлять товары в корзину.
* Оплачивать товары в корзине и получать подтверждение по электронной почте.

### Владельцы магазинов могут:

* Создавать, редактировать или удалять товар, а также указывать его доступное количество.
* Просматривать заказы покупателей, по которым была подтверждена оплата.
* Отмечать заказ как отправленный. Для этого необходимо указать ID отслеживания и приложить фото-подтверждение.

### Системные администраторы могут:

* Просматривать логи.
* Переопределять некоторые права доступа для ручного решения ситуаций.
* Замораживать аккаунт на время расследования. Замороженные аккаунты не могут выводить деньги, продавать или покупать товары.
* Отправлять личные сообщения любому пользователю.
